Mod rules

When every comma-separated item in "If rolled" has been rolled on any wheel, the mods in "Add mods" join your run. Use | for "or", so Bard | Healer, Calamity Mod means (Bard or Healer) and Calamity Mod. Names must match an option exactly (capitals don't matter). Mods added by one rule count as rolled for the others. Tick "Always required" for mods a class can't run without; the cancel list leaves those in place and only waives the rest as compat mods.

    Mod difficulties

    Each wheel here joins the difficulty window, which opens after Spin all while "Mod difficulty roll" is on in Your run. A wheel only appears when its mod is in the run, either rolled or added by a rule. Leave the mod field blank to always include the wheel.
